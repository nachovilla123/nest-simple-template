## Inicio Rápido

1. Instalar dependencias: `npm install`
2. Iniciar servicios Docker: `docker-compose up -d`
3. Copiar archivo de entorno: `cp .env.example .env`
4. Iniciar aplicación: `npm run start:dev`
5. Acceder a pgAdmin: http://localhost:5050
